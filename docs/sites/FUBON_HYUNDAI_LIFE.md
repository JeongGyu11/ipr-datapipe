## 10. 후속 조사 (2026-08-04)

- **최종 분류**: `INVALID_CONFIG_URL` (기존 MANUAL_REVIEW_REQUIRED 에서 원인 구체화)
- **현재 실패 단계**: **공시실 탐색**
- **정확한 원인**
  - config URL 이 회사 홈페이지입니다.
  - 홈에서 공시실 메뉴를 열어(`page.evaluate("goMenu('CUSI150000000000')")`)
    하위 메뉴 HTML(`POST /menu/viewPage/cmmn/CUSI150000000000`, 3,376 B)을 받았으나
    **공시이용 매뉴얼 / 보험가격공시실 / 경영공시실 / 금융기관보험대리점공시실 / 기타공시실**
    5개만 있고 '보험상품공시실' 항목이 노출되지 않았습니다.
  - 하위 화면 3개(`CUSI150101000000`, `CUSI150212000000`, `CUSI150515000000`)를 직접 받아
    본문을 검사했지만 약관·사업방법서·상품요약서·판매기간 문자열이 하나도 없었습니다.
- **참고**: `/common/isLogin`, `/main/getMainPageSetting` 등 일부 XHR 은 `{"g":"..."}` 형태로
  암호화되어 있으나, 메뉴 조회(`/menu/viewPage/cmmn/...`)는 평문입니다.
- **후속 작업**: 실제 브라우저에서 공시실 전체 메뉴를 펼쳐 상품공시 메뉴의 존재 여부와 menuId 를 확인.
